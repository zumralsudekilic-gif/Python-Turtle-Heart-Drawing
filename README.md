# Python Turtle Heart Drawing 

A simple Python project that uses the Turtle graphics library to draw a heart.

## Technologies 
- Python 3 
- Turtle Graphics

## About
This project was created to practice basic Python programming concepts and Turtle graphics commands.

The project includes user input, pen control, movement, loops, random numbers and coordinate-based drawing.

## Concepts Practiced
- input()
- int()
- len()
- range()
- randint()
- penup() and pendown()
- goto() and setpos()
- forward() and backward()
- left() and right()
- color() and pensize()

* Created for learning and practicing Python Turtle graphics.
